# 教师名单与批量管理

入口：教师工作台 → 班级管理 → 选择班级 → 人员信息。

## 将学生转到另一班

1. 搜索或筛选学生，勾选多人；全选只作用于当前筛选结果。已选人数会包含被后续筛选隐藏的学生，页面会提醒。
2. 点击「批量管理」，选择「转到其他班级」及目标班级。
3. 可选择目标小组，或选择「新建小组并加入」，直接填写组名。
4. 点击「预览操作影响」，核对人数、源班/目标班、退组及课程/未交任务影响，再确认执行。
5. 完成后原班、目标班人数和分组关系自动刷新。重复确认不会重复创建小组或成员关系。

学生只能归属一个班级。转班会退出原班及其全部小组；原提交、成绩、学习记录仍归属原课程，不会搬成新课程记录或被删除。学生仍可查看已公布成绩，但失去原班任务详情与作答权限。有已开始但未提交的测验时，必须先提交或由老师关闭任务，才能转班。

## 分配或调整小组

在「批量管理」选择「分配 / 调整小组」，可加入已有小组或当场新建。默认保留原有组，也可选择退出自己管理的本班其他组。老师不能调整其他老师的组；管理员可管理全部组。新建相同名称的小组会复用已有组，避免重试产生重复组。

## 导入名单

1. 点击人员信息旁的「批量导入学生」，下载 CSV 模板（Excel 可打开），或直接使用含「姓名」「邮箱」列的原有 Excel。可带「学号」，仅本次核对，不存入账号。
2. 上传 xlsx/xls/csv 文件；每次最多 200 行、2 MB，只读取第一个工作表。
3. 如有新账号，在窗口填写统一初始密码（至少6个字符，不超过72字节）。也兼容名单中选填的「初始密码」列；逐人填写时优先使用该列。密码仅用于新账号，老师通过私下渠道交付，学生登录后可修改。
4. 上传预览并逐行核对，再确认导入可用行：同班已有账号跳过，未分班学生直接复用账号入班，其他班或无法使用的邮箱提示冲突。已有姓名和密码不变。
5. 错误行不会影响已成功行。可修正名单重新上传，或重新校验后重试；已成功账号会跳过。预览有效期30分钟，名单/密码设置变化或账号状态改变需重新预览。

转班、分组每批最多200人。新建班级的老师无需先关联课程，即可管理名单。班级列表仅展示有管理权限的班；外班学生需由具有源班和目标班权限的老师转班，或请管理员处理。
